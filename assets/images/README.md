# Images Folder

Place your portfolio images here.

## Recommended Files

### Profile Photo
- **Filename:** `profile.jpg` or `profile.png`
- **Size:** 400x400px (square)
- **Format:** JPG or PNG
- **File size:** < 200KB
- **Quality:** High resolution, professional photo

### Project Screenshots (Optional)
- **Attendance Dashboard:** `project-attendance-dashboard.jpg`
- **Visitor Log System:** `project-visitor-log.jpg`
- **Monitoring Tools:** `project-monitoring-tools.jpg`
- **Size:** 1200x800px (landscape)
- **Format:** JPG or PNG
- **File size:** < 500KB each

### Other Images
- **Favicon:** `favicon.ico` or `favicon.png` (32x32px)
- **Open Graph Image:** `og-image.jpg` (1200x630px for social media sharing)

## Image Optimization Tips

1. **Compress images** before uploading:
   - Use tools like TinyPNG, Squoosh, or ImageOptim
   - Target: < 200KB for photos

2. **Use appropriate formats:**
   - Photos: JPG
   - Graphics/logos: PNG
   - Icons: SVG (if possible)

3. **Provide alt text** in HTML for accessibility

<!-- Profile photo in hero section -->
