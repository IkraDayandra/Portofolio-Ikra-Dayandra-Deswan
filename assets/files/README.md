## CV Best Practices

1. **File naming:** Use clear, professional names
   - ✅ Good: `Ikra_Dayandra_CV.pdf`
   - ❌ Avoid: `resume-final-v3.pdf`

2. **PDF optimization:**
   - Ensure text is searchable (not scanned image)
   - Use standard fonts (Arial, Calibri, Times New Roman)
   - File size < 2MB for fast download

3. **Content alignment:**
   - Ensure CV matches portfolio website content
   - Include same contact information
   - Highlight same key achievements
